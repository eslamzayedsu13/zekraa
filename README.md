# Zekraa

Build Zekra — ذكري | Online Store



Before starting, use and review the UI UX Pro Max skill and the Frontend Design skill from GitHub, if available in the environment. Follow their best practices throughout the project. Do not waste time installing duplicate skills; proceed with the strongest available design guidance.



Brand & Design Direction



Create a premium, modern, bilingual e-commerce store called ذِكرى (Zekra), selling thoughtful gifts for engaged couples, romantic keepsakes, accessories, and unique lifestyle products.



I do NOT want a generic AI-generated storefront. Avoid predictable templates, excessive gradients, glassmorphism, oversized rounded cards, unnecessary animations, and the typical AI website aesthetic.



Design a clean, elegant, editorial-style shopping experience with:



- A distinctive visual identity, sophisticated typography, generous whitespace, and carefully balanced layouts.

- A refined palette of warm ivory, charcoal, and muted sage or dusty rose accents.

- Beautiful product photography, tasteful art direction, and subtle micro-interactions.

- A premium, memorable homepage that feels like a real, professionally designed brand.



Essential Features



- Fully responsive design, with mobile-first attention to detail.

- Arabic and English languages with a working language switcher. Arabic must use proper RTL layout; English must use LTR.

- EGP (ج.م) as the default currency, with properly formatted prices.

- Homepage with a distinctive hero section, curated collections, featured products, bestsellers, and a thoughtful brand story.

- Product listing, category filters, search, sorting, product details, image gallery, and product variants where applicable.

- Functional cart, quantity controls, wishlist, and a streamlined checkout experience.

- Customer accounts, order history, and order tracking UI.

- Contact page, FAQ, shipping and returns policies.

- Admin dashboard for managing products, categories, inventory, orders, and customers.

- Use reusable components and a scalable architecture. Prepare the project for real backend integration, authentication, and Egyptian payment and shipping providers.



Execution Rules



Build the actual working storefront, not just a visual mockup. Make navigation, filters, language switching, and cart interactions functional. Use realistic sample products and prices in EGP. Do not invent successful payment or order confirmations without a working backend.



Prioritize design quality, usability, accessibility, performance, and clean code. Make smart design decisions independently instead of asking unnecessary questions. Start implementing immediately and deliver a polished, cohesive brand experience that feels custom-designed for Zekra.
